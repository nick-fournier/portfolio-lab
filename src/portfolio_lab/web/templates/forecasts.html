1. How it works

What it predicts

Each stock's return over the next month minus that month's average return across all stocks: how much it beats or trails the typical stock.

ri=Ri−R‾

Ri: the stock's total return next month (price change plus dividends, in plain %). R̄: the average of R over all stocks that month. Example: the market rises 3% and the stock 5%, so r = +2%. The market's own rise or fall is removed because it's the same for every stock and can't help rank them. Every number on this page is in these units.

Inputs

For each stock at each month end, using only what was known then. Each input is turned into a percentile among that month's stocks (x), so a 5% earnings yield in 2008 and in 2021 are compared with their own month's stocks.

The model

Step 1, linear model. A straight-line fit across all stocks and earlier months gives a first forecast:

r^lin=b1x1+b2x2+…+bnxn

About 25 inputs; momentum gets separate weights in bear and rebound markets. The b's are kept small by a penalty (ridge regression). For training, each month's most extreme 1% of returns at either end are clipped so a few blow-ups don't dominate.

Step 2, trees on what the line misses. On the training months, the leftover (residual) is each stock's actual return minus its linear forecast. Gradient-boosted trees learn to predict that leftover from the same inputs plus the market environment, which catches thresholds and interactions a straight line can't:

c=trees(inputs, market)≈r−r^lin

Step 3, blend. The trees' correction is added at half strength, since part of what they learn is noise:

r^=r^lin+0.5·c

How it's tested

Walk-forward: each year from {{ h.start }} to {{ h.end }} is predicted by a model trained only on earlier years, then compared with what actually happened. All stocks, including companies that later failed.

3. From forecast to expected return

A portfolio optimizer needs each stock's expected return as a believable number. The forecaster's own numbers are too extreme, but its ranking is sound, so the numbers can be rebuilt from the ranking. Grinold's rule does that in three pieces:

αi=IC·σi·zi
  1. Where it ranks (z): the stock's forecast percentile this month, converted to a standard score: 0 for the middle stock, about +2 near the top, −2 near the bottom.
  2. How much to trust the ranking (IC): the ranking's skill measured on earlier years, about 0.03–0.04. A perfect forecaster would be 1, so this shrinks everything to a realistic size.
  3. How much the stock moves (σ): its typical monthly swing over the past year. The same rank means a bigger expected gap for a stock that moves 12% a month than for one that moves 4%.

α: the expected return over the average stock next month, in the units of part 1. Example: z = +2, σ = 8% a month gives α = 0.04 × 8% × 2 = +0.64%.
