Ranking (IC)
Each month, rank all stocks by forecast and again by their actual return that month, then take the correlation of the two rankings (Spearman): +1 = same order, 0 = no relation, −1 = reversed. Averaged over months. Real stock signals typically score 0.02–0.05.
Years right
Years whose average IC was above zero.
Best vs worst tenth
Each month, the average return of the tenth of stocks with the highest forecasts minus the tenth with the lowest, compounded over a year, before costs.
Tested
Each year predicted by a model trained only on earlier years; all stocks, next-month return relative to that month's average.

The forecaster: a linear model on health, momentum (different in bear and rebound markets), year-on-year changes and valuation, plus gradient-boosted trees trained on what it gets wrong, added at half strength. "What it uses": how much the ranking drops when a group's values are shuffled between stocks. The ranking is reliable; predicted sizes are not (they swing year to year), so use the order, not the numbers.
