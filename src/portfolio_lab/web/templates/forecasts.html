How the forecast is built

1. Linear model. Each stock's inputs are converted to percentiles within the month (x), and a straight-line fit gives a first forecast:

linear forecast = b₁·x₁ + b₂·x₂ + … + bₙ·xₙ

About 25 inputs: health and profitability, momentum (with separate weights in bear and rebound markets), year-on-year changes, valuation, industry-relative versions. The b's are fit across all stocks and earlier months, with a penalty that keeps them small (ridge regression).

2. Trees on what the line misses. On the training months, the leftover is each stock's actual return minus its linear forecast. Gradient-boosted trees learn to predict that leftover from the same inputs plus the market environment, which catches thresholds and interactions a straight line can't.

correction = trees(inputs, market) ≈ actual − linear forecast

3. Blend. The trees' correction is added at half strength, since part of what they learn is noise:

forecast = linear forecast + 0.5 × correction

From forecast to expected return (for the optimizer)

The ranking is reliable but the sizes are exaggerated, so mean-variance would get expected returns rebuilt from the ranking with Grinold's rule:

expected extra return = IC × volatility × score

Score: the stock's forecast rank, standardized (0 for the middle stock, about ±2 near the ends). IC: the ranking's measured skill (about 0.04), which shrinks everything to a realistic size. Volatility: how much the stock typically moves in a month, so riskier stocks get proportionally larger expected returns. Per unit of risk, every stock's expected return is IC × score: it depends only on its rank. Example: score +2, 8% monthly volatility → 0.04 × 8% × 2 = +0.64% a month.
